# 环境、隐含条件和状态清单

## 运行条件

| 条件 | 原会话 | 可分发版本 |
|---|---|---|
| 宿主 | 能执行 Python 和读取本机文件的智能体 | 同样需要本地执行能力；分析由当前宿主完成 |
| Python | 3.9.6，标准库脚本 | Python >=3.9，`requirements.txt` 明确零第三方包 |
| HTTP | urllib 临时采集脚本 | 系统 curl；凭证通过 stdin 传递，不进入命令行参数 |
| 其他 Skill | 会话有大量已安装技能 | 运行本技能不依赖任何其他本地技能或 MCP |
| 模型 API | 宿主的模型推理 | 不添加分析 API Key；不同模型的语义取舍不保证逐字一致 |
| TikHub | 本机找到的历史凭证 | 使用者自己的 `TIKHUB_API_KEY` 或 `--prompt-key` |
| Just One API | 当时从剪贴板取得令牌 | 默认关闭；可选探针使用 `JUSTONE_API_TOKEN`，单独授权 |
| 数据目录 | 临时绝对路径和中文输出目录 | 所有命令显式 `--run/--out`，证据路径相对运行目录 |
| 时区 | Asia/Shanghai | 固定 UTC+08:00，不依赖运行机器默认时区 |

无 pip 安装步骤。macOS 本机与独立 venv 用于本次验收；代码有 POSIX/Windows 文件锁分支，未在真实 Windows/Linux 主机验证时不得宣称这些平台已实测。纯托管聊天客户端不能因“支持 Skill”就被视为能运行此代码。

## 状态文件

| 文件 | 作用 | 是否随公开仓库提供 |
|---|---|---|
| `config/fde.json` | 未授权默认计划与固定口径 | 是 |
| `plan.json` | 本轮主题、日期、范围、预算、用户授权 | 用户运行时生成，忽略提交 |
| `authorization.json` | 授权时完整计划哈希，首笔请求前也必须匹配 | 用户私有，不能沿用旧授权修改计划 |
| `quotes.json` | 匿名官方端点报价与时间 | 用户运行时生成；历史样本不当现价 |
| `ledger.json` | 每次尝试、成功/失败、预留费用、参数及响应哈希 | 用户运行时生成；回放从精简快照重建 |
| `responses/` | 成功/失败证据缓存，内容可能含全文 | 用户私有；不自动上传 |
| `candidates.json` | 去重数据、选择理由和补采标记 | 用户私有；回放包含冻结的历史选择 |
| `verification-selection.json` / `supplement-selection.json` | 开始核验的账号集合、首次三篇结果确定的补采两号 | 用户私有，续跑不重新挑最高两号 |
| `analysis.json` | 宿主写作、证据 ID 与正文哈希 | 用户私有；回放包含摘要样稿 |
| `billing.json` | 实际费用的证据摘要 | 可选；无记录则不能宣称实际扣费 |
| `justone-plan.json` / `justone-authorization.json` / `justone-ledger.json` | 可选数据源独立人民币预算、授权哈希和质量停止状态 | 用户私有，不影响 TikHub 美元账本 |
| `snapshot.json` | 原 50 次尝试、搜索/历史/指标的白名单精简字段 | 是，不含凭证、全文和个人余额 |
| `expected.json` | 七篇计算结果和总体数量 | 是，固定回归期望 |

`billing.json` 是独立账单记录，不能拿 `reserved_usd` 假装实际扣款；原样本只有精简的费用核对结论，私人控制台页面和余额没有公开。

## 缓存与迁移

成功缓存按操作和参数指纹复用，复算验证内容哈希及账本绑定。失败或中断仍保留预留，禁止删账本或新建目录继续同一预算。显式重试最多一次并计入原上限。

移动目录时整套复制计划、账本、响应和编辑文件；不能只复制 CSV 当作可继续收费查询的状态。公开回放计划标记 `data_kind=replay`，程序禁止在其中发付费查询。真实新研究从 `init` 开始，不继承维护者授权、报价或 Key。

导出器 `scripts/import_pilot.py` 只读取显式指定的旧试采文件，按字段白名单转换；它不扫描个人目录或读取凭证。仅用于迁移这一来源格式，不能承诺任意旧工程都能导入。

网络数据、自然语言选择和文章内容会变化。固定样本保证数学口径可复算，不能保证未来网络搜索仍然给出相同文章。
